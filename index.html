给参赛 AI 的初始提示词

直接复制使用

目标是拿到更高分、争取更高排名。复制给 AI，让它输出完整 strategy.js，再到策略实验室导入。

包含竞技目标、游戏规则、输入接口和代码输出要求；基础食物数量随本局设置更新。

01

比赛与计分

  • 30×30地图，2～10名玩家；初始长度5格，每回合必须走1格。
  • 所有策略读取同一回合的完整局面，同时提交行动。
  • 允许头部穿过自己的身体，禁止180度反向移动。
  • 一个食物占一格，吃到后长度和分数各增加1。
  • 所有玩家按分数排名，死亡玩家的分数冻结。同分并列。
  • 500回合或全部死亡时结束。剩一条蛇时继续比赛。
02

碰撞与食物

  • 撞边界或其他蛇身体会死亡。多个蛇头进入同一格、交换头部位置时全部死亡。
  • 合法且不吃食物的移动会先腾出尾格，即使该蛇随后在本回合碰撞死亡；同格还有身体段则仍占用。
  • 本回合死亡的身体仍参与碰撞判定，全部判定后统一清除。
  • 死亡掉落 floor(长度×30%) 个食物，优先在原身体格生成，其余放入附近空格。
  • 食物不生成在存活蛇身体或已有食物上；空间不足时只生成容得下的数量。
  • 基础食物数量默认20＋4×玩家数，可调整；低于下限才补充，掉落超出时不会删除食物。
03

策略如何参赛

  1. 复制参赛提示词，让AI输出独立JavaScript模块。
  2. 在策略实验室导入.js文件或粘贴代码，保存并勾选参赛。
  3. 试运行检查接口，再进行单局或多局测试。参加排位请先注册；修改注册代码请复制为新版本。
  4. 每局创建独立Worker，模块变量可记忆局内信息，每局重置。
  5. 代码加载失败、异常、输出非法、反向或超时，都会淘汰该玩家并冻结分数。

04

策略接口

export default function decide(state) {
  // state.you：自己的玩家ID
  // state.turn：已完成回合，首回合为0
  // state.width / height：地图尺寸
  // state.food：[[x,y], ...]
  // state.snakes：所有玩家
  // snake.body：头 → 尾的坐标数组
  // snake.alive / score / direction
  return { direction: "down" };
}

坐标从左上角[0,0]开始。支持up、right、down、left，也可直接返回方向字符串。

运行说明

本地浏览器执行JavaScript策略，无需账号或API密钥。每次调用在Worker内部测量50ms预算，另有250ms无响应保护。实际耗时受设备和浏览器影响，多局测试请保持页面在前台。Worker隔离界面并限制网络连接，但不构成面向不可信代码的安全沙箱。回放记录实际局面，导入后只播放记录，不运行参赛代码。
