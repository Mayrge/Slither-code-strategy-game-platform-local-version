# Snake Arena · 贪吃蛇策略竞技台

已经实现：30×30棋盘，最多10条蛇，500回合，自碰免死，统一按长度分数排名，死亡分数冻结，30%身体长度转为食物。

## 启动

需要Node.js 20或更新版本，无需安装任何npm依赖。

在此目录执行：

```powershell
npm start
```

打开 http://127.0.0.1:3080 。Windows也可以双击 `启动竞技台.cmd`。

重复双击时会识别并打开本目录已经运行的竞技台，不会再次启动服务。3080被其他程序占用时会自动尝试后续端口，并打开实际使用的地址。

端口被占用时可以更换：

```powershell
$env:PORT=3081
npm start
```

服务只监听本机127.0.0.1。关闭运行服务的终端即可停止。

## 使用

1. 对战页自带10个不同参数的示例策略，点击「开始比赛」即可观看；示例名称和代码已注册锁定，修改请复制为新版本。策略实验室将它们收在默认折叠的「系统选手」文件夹中，需要时展开勾选；对应的独立文件在 `strategies/examples/`。
2. 「策略实验室」点击「添加参赛选手」，自定义名称、蛇身颜色（选择器或十六进制色值）和代码，可粘贴代码或导入.js/.mjs文件。保存后刷新仍保留。选手库可超过10人，每场勾选2～10名；满员时新选手先进入候选列表。
3. 点击「一键复制参赛提示词」，交给AI生成策略；「规则与参赛」页可查看全文，明确以高分和排名为竞技目标。接口及全部规则在 `RULES.md`。
4. 保存策略后，可先「试运行当前策略」检查前12步，再参加对战。示例是入门测试对手，并非最优程序。
5. 暂停、单步、选择速度、拖动回放进度、点击排名聚焦某条蛇。结束时显示全部玩家最终排名。
6. 导出回放后可以再次导入播放，回放不含代码，也不会执行代码。所有导出文件同时保存在项目的 `exports` 文件夹，并提供下载链接，兼容限制自动下载的内置浏览器。
7. 「多局测试」支持4、10、20、50、100、500局及1～1000局自定义。每组同地图种子，随机排列并完整轮换出生位置；下一组换新地图种子，相同赛程种子可复现安排。末组不完整时，各位置次数最多相差1。显示平均积分、平均长度、第一名次数和存活率，支持停止和导出完整局的统计。
8. 赛程页的「单局记录与回放」可按局号、种子或获胜者筛选，每页20局；点击「查看第X局回放」在对战页播放、单步、拖动进度或导出回放，点击「返回赛程」继续选局。测试进行中也可观看已完成局。
9. 「我的赛程」支持新增、命名、保存和切换。新增赛程保存当前勾选选手的名称、颜色和代码快照；开始前可修改局数和种子，也可点击「使用当前参赛选手」更新策略快照。已开赛的赛程保留原有参数和记录，查看历史赛程时点击「新增赛程」准备下一组比赛。删除赛程会在同一笔存储操作中删除积分榜、设置、策略快照及全部回放，不保留回收副本；运行中的赛程需要先停止。
10. 每局回放压缩保存在当前浏览器的IndexedDB中，重新打开后可在「我的赛程」中查看所有已保存赛程。仅保留完整局，停止时未完成的局不计入统计。更换浏览器或端口、清理浏览器数据会影响这些本地记录；重要回放请导出。存储空间不足时停止测试并保留已经保存的完整局。

`examples/demo-replay.json` 附带一场10名示例策略、完整500回合的实际对局，可通过「导入回放」直接播放。`preview.jpg` 是实际运行截图。

策略存入当前浏览器的本地存储，重新打开仍保留。换浏览器、清理浏览器数据或换端口会使用不同存储；重要代码请下载备份。暂停后修改的策略用于下一局，当前局继续使用开赛时加载的版本。

## 程序接口

```js
export default function decide(state) {
  return { direction: "down" };
}
```

支持JavaScript代码。当前版本不运行Python或C++程序。每条蛇使用独立Worker，每步50ms内部执行预算；另有250ms无响应保护。代码异常、非法输出、反向及超时都会淘汰玩家。完整局面包含所有蛇和食物，局内变量可保存记忆。

保持比赛页面在前台，浏览器的后台节流或设备负载可能影响运行速度及超时。本地Worker不属于严格安全沙箱；正式面向不可信选手的赛事需要服务端隔离。没有调用任何AI接口，不需要账号或API密钥。

## 文件结构

- `index.html` / `src/styles.css`：竞技台页面。
- `src/engine.js`：独立、确定性的回合裁判。
- `src/runner.js` / `src/strategy-worker.js`：策略执行与预算控制。
- `src/bots.js`：10种示例选手。
- `src/replay.js`：回放校验及比赛积分。
- `src/ranking.js` / `src/ranking-store.js`：三级排名、定位、资格校验及独立持久保存。
- `agent-sandbox/`：供 AI agent 独立迭代的空白测试环境、单步接口和资料打包工具。
- `src/app.js` / `src/renderer.js`：控制逻辑与棋盘绘制。
- `strategies/starter.js`：供AI参考的入门代码。
- `server.mjs`：零依赖本地服务。
- `tests/`：关键规则测试。
- `examples/demo-replay.json`：完整示例对局。
- `exports/`：用户导出的代码、回放和统计文件，每次导出生成唯一文件名。

## 永久排行榜与选手注册

首页展示三级联赛：华山论剑、凌云争锋、潜龙试剑，每级最多10个席位。首页金、银、铜卡只展示最高联赛前三名。10名初始策略自动注册为“系统选手”。未进行比赛的选手显示为待定位，不按示例顺序虚构排名。

在策略实验室添加选手，保存名称与代码后点击“注册选手”。注册后名称与代码不可修改；颜色和标签可以调整。修改策略请点击“复制为新版本”，使用不同名称重新注册。原先改过的草稿会保留，系统原版独立补齐。

赛程页勾选注册选手，点击“一键生成排位赛程”。初始榜选择2～10名选手；已有榜时，单选待定位选手可自动安排定位对手，同级排位需选择连续名次，交界挑战可使用专用按钮。排位统一使用30×30、500回合、60个基础食物、初始长度5和默认执行预算。最低50局，局数会补齐整组出生位置轮换。每级10人时，新人加10名对手共11人采用10种组合，每局10条蛇；每100局新人参赛100局，每名原选手参赛90局，所有人均完整轮换出生位置。

定位先从已有人数的中间级别开始。根据新人和每名对手共同参赛时的平均名次积分差决定定位；领先全级时向上挑战，落后全级时向下定位。最高级表现第一可直接成为榜首。共30个名额满员后，被挤出的末位进入候补并可再次挑战最低级。联赛内部按同场平均名次积分更新；相邻级别通过交界挑战调整名额。同分保留已有次序，新人同分不挤到对手前面。

完成赛程后，手动点击“一键导入排行榜”。普通赛程也有此按钮，但必须满足注册版本、统一配置、完整比赛、完整位置轮换及当前排名方案。旧版缺少代码快照的赛程、未注册时进行的比赛、中断比赛、排名变化后过期的排位赛不能导入，页面会显示原因。导入前逐局核验保存的回放与结算；排名与导入记录在一个独立事务中保存，防止重复导入和多页面冲突。

删除赛程会物理删除赛程和全部回放；**已经导入的排名、注册选手和精简变动记录独立保留，不受删除影响**。数据保存在当前浏览器的当前站点本地存储中，重新打开会恢复；清除浏览器站点数据、更换浏览器或更换端口不会共享这份本地榜单。

## 供 AI Agent 自行迭代的资料包

在「规则与参赛」页点击「一键下载 AI Agent 资料」。ZIP 包同时保存到项目的 `exports` 文件夹，包含迭代提示词 `PROMPT.md`、原始参赛提示词 `CONTESTANT-PROMPT.md`、`blank-map.json`、Node.js 测试工具、正式裁判源码、10份系统策略、入门 `strategy.js` 和使用说明。原有的一键复制提示词入口保留。

解压后交给能读写文件并运行命令的 agent，要求它先读 `PROMPT.md`。环境无界面，支持批量对战、逐步观察和推进；`trace.jsonl`记录全部实际回合，`inspect`可按局号和回合查询蛇身、食物、动作、分数及死亡原因。每次修改策略后重新运行即可载入新版本，测试结果独立保存在输出文件夹，不读取或写入正式排行榜及赛程。最终的 `strategy.js` 可直接导入竞技台。

环境需要 Node.js 20+，无需安装 npm 依赖。单独重新生成资料包可运行 `node agent-sandbox/package-kit.mjs`。具体命令和程序调用接口见 `agent-sandbox/README.md`。
